## 1. File-by-File Implementation Scope

### A. Adaptive Intensity BGM Stem & VOX Bark Packager (`src/GameAssetExporter.h/.cpp` [New], `CMakeLists.txt`)
Implement platform-neutral `GameAssetExporter` (compiled inside `tcs_core` / `tcs_core_isolation`):
1. **Phase-Locked Adaptive Intensity Stem Exporter (`exportAdaptiveBgmStems`):**
   - Groups tracks by tag/prefix (`calm`, `stealth`, `tension`, `combat`, `boss`) or explicit track index map, renders each intensity layer over the exact same `[startBeat, endBeat]` window via `exportSeamlessLoopWav` (ensuring identical sample length and zero-click wrap so Godot 4 `AudioStreamSynchronized` can crossfade between stems cleanly).
2. **VOX Bark Batch Processor (`processVoxBarkBatch`):**
   - Takes a folder or list of recorded VOX WAVs (e.g., from Phase 7 VAS takes), auto-trims leading/trailing silence below `-50 dBFS` (preserving 15 ms head / 40 ms tail fades), normalizes each bark to `-16.0 LUFS` via `src/LoudnessMeter.h` (peak clamped `<= -1.0 dBFS`), and writes sequentially named game files (`{actor}_{action}_01.wav`..).
3. **Godot 4 / `godot4-asset-vault` Manifest Export (`writeAudioManifestJson`):**
   - Organizes exported assets into `<export_root>/bgm/`, `<export_root>/sfx/`, `<export_root>/ambient/`, `<export_root>/vox/` and emits `<export_root>/audio_manifest.json` containing `{ schema_version, bpm, assets: [ { path, category, loop, duration_sec, lufs, peak_db, variation_group } ] }` ready to drop straight into `TacPlanShooter` or `godot4-asset-vault`.
