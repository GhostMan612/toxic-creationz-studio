Create a toggleable `"VO Booth"` dockable panel (`ScriptPrompterComponent`) inside `MainComponent` (dark studio theme via `StudioLookAndFeel`, `juce::FontOptions` everywhere):
1. **Script Reader & Cue Markers:**
   - Load `.txt` / `.md` scripts from disk or receive script text via RPC (`vo.set_script`), persist script text + font size + WPM inside the `te::Edit` `ValueTree` state so scripts reload with the session.
   - Adjustable font size (`14..36 pt`), WPM auto-scroll toggle (`80..220 WPM`) synced to transport play/stop, and a `+ Drop Cue Marker` button that writes timestamped line markers onto the Tracktion timeline (`edit->getMarkerManager()`).

   - Configurable ADR cue state: `enabled` (bool), `beepIntervalSec` (`0.5..1.0s`, def `0.65s`), `lineDurationSec` (`1.0..15.0s`, def `4.0s`).
