## 1. File-by-File Implementation Scope

### A. SFX Forge Panel (`src/SfxForgeComponent.h/.cpp` [New], `src/MainComponent.h/.cpp`, `CMakeLists.txt`)
Create a dockable `"SFX Forge"` panel in `MainComponent`, modeled on `BgmGeneratorComponent`:
1. **Forge controls:** Category selector (all 8 `SfxForgeEngine` categories), seed field + randomize button, variation count (`1..16`), duration, and `Forge Variations` button. Generation runs `renderSfx` / `generateSfxVariations` on a background thread (never blocking the message thread) and lists the results with per-variation audition buttons.
2. **Instant audition:** Clicking a variation's audition button plays the rendered buffer immediately through `UiSoundService`'s one-shot monitor voice (no track, no edit mutation, no file write).
3. **Export:** `Export` writes selected variations as 44.1 kHz / 16-bit WAVs (`{category}_{seed}_{index}.wav`) to the `SfxForge` dir and, when a Godot export root is set, drops them into `<export_root>/sfx/` for the `WO-024` packager's manifest.
4. **UI-sound preset bank:** A preset row of the 7 touch sounds — `click`, `blip`, `beep`, `success`, `back`, `error`, `toggle` — each showing its deterministic seed + pitch, each auditionable, and each re-forgeable. These are the sounds §1.B plays.

### B. UI-Sound Service (`src/UiSoundService.h/.cpp` [New], `src/MainComponent.h/.cpp`)
1. **Pre-rendered bank at startup:** On first use (lazy, background thread), render the 7-sound §1.A bank from `SfxForgeEngine` (`ui_click` for `click`/`back`/`toggle`, `sci_fi_pulse` for `blip`/`beep`/`success`/`error` at short durations) and cache the buffers. All sounds strictly `< 150 ms`. Deterministic seeds so the studio's touch sounds are identical on every launch.
2. **Lock-free one-shot playback & ASAN-safe teardown:**
   - Register a lightweight `juce::AudioIODeviceCallback` (skipped from touching hardware when `--smoke-test` is active) using lock-free atomic voice slots (zero mutexes and zero heap allocations in the audio callback).
   - Expose `void renderCallbackBlock (float* const* outputs, int numChannels, int numSamples)` called by the live audio callback and directly callable in headless `--smoke-test`.
   - `UiSoundService::play (const juce::String& name)` is callable from any message-thread UI event; never blocks, never touches `te::Edit`, never writes a file.
   - **Mandatory Teardown Order:** `~UiSoundService()` MUST cancel/join any background render thread and remove its `AudioIODeviceCallback` from `DeviceManager` *before* `te::Engine` / `DeviceManager` destroys.
3. **Hook points (`MainComponent` owns the calls):** Primary button presses, tab/dock switches, transport play/stop, and dialog open/close. Keep the hook list small and explicit — no global mouse listener, no `LookAndFeel` paint-path sounds.
4. **App-Level Settings (Zero Edit Mutation):** `UI Sounds` toggle (default ON, volume `-18.0 dB`) in Settings + a visible mute button in the studio header. Persist `uiSoundsEnabled` and `uiSoundsVolumeDb` in **app-level property storage** (`te::Engine::getPropertyStorage()` / `juce::PropertiesFile`, redirected to a temp dir under `--smoke-test`) — **never** in `te::Edit`'s `ValueTree`, so toggling mute never dirties or mutates any song session.

### C. RPC + MCP Surface (`src/DawIpcServer.cpp`, `mcp/daw_mcp_server.py`, `mcp/test_mcp_server.py`)
1. **New JSON-RPC 2.0 methods:**
   - `sfx.render_ui_bank`: `{ "seed"?: int }` → re-renders the §1.B bank and returns `{ "seed", "sounds": [ { "name", "duration_ms" } ] }`.
   - `sfx.set_ui_sounds`: `{ "enabled": bool, "volume_db"?: float }` → updates and persists §1.B app-level settings and returns `{ "enabled", "volume_db" }`.
2. **New FastMCP tools (`mcp/daw_mcp_server.py`):**
   - `forge_ui_sound_bank(seed: int = 42)` → `sfx.render_ui_bank`
   - `set_ui_sounds(enabled: bool = True, volume_db: float = -18.0)` → clamps `volume_db` (`-60.0..0.0`) and forwards `sfx.set_ui_sounds`
3. **Python Unit Tests (`mcp/test_mcp_server.py`):** Add **4 mocked-RPC unit tests** covering `forge_ui_sound_bank` defaults/seed forwarding, `set_ui_sounds` clamping/forwarding, `forge_game_sfx_batch` `ui_click` prefix/export parameters, and source-marker verification for `UiSoundService` / `SfxForgeComponent` (expanding Python suite cleanly by +4 tests).
