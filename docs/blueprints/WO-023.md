## 1. File-by-File Implementation Scope

### A. Procedural SFX & Foley Synthesizer (`src/SfxForgeEngine.h/.cpp` [New], `CMakeLists.txt`)
Build a deterministic, zero-external-asset, platform-neutral C++20 game SFX synthesis engine (compiled inside `tcs_core` and verified by `tcs_core_isolation`):
- **8 Procedural SFX Categories (`SfxCategory`):**
  1. `gunshot_tactical` (transient crack + shaped bandpass noise tail + sub thump; supports `suppressed` parameter)
  2. `breach_explosion` (sub-bass pitch drop + multi-band debris crackle + resonant low rumble)
  3. `footstep_surface` (surface parameter: `concrete`, `metal`, `gravel`, `wood` — dual heel/toe filtered impulses)
  4. `ui_click` (crisp tactile pitch-enveloped sine/triangle chirp for tactical HUD buttons & menus)
  5. `melee_impact` (metallic ring cluster + low body thud for blades/blunt hits)
  6. `door_breach` (latch click + hydraulic/wood splinter burst)
  7. `sci_fi_pulse` (FM/phase-modulated frequency sweep + resonant filter ping)
  8. `ambient_drone` (evolving detuned harmonic drone + slow filtered noise bed for room tone / tension)
- **Seeded Variation Batcher (`generateSfxVariations`):**
  - Generates `N` (`1..16`, default `6`) distinct non-repetitive takes (`{prefix}_01.wav`..`{prefix}_06.wav`) from a base `seed`, applying controlled micro-randomization to pitch (`+/- 1.5` semitones), filter cutoff (`+/- 12%`), and transient decay (`+/- 10%`) so repeated footsteps or gunshots never sound machine-gunned.
  - Auto-normalizes each WAV to target peak (`default -1.0 dBFS`) and writes 44.1 kHz / 16-bit WAV via `juce::AudioFormatWriterOptions`.

### B. Zero-Click Tail-Wrapped Seamless Loop Renderer (`src/MixdownExporter.h/.cpp`)
Extend `MixdownExporter` with `exportSeamlessLoopWav(te::Edit&, double startBeat, double endBeat, const juce::File& outWav, double targetLufs = -14.0)`:
- Renders `[startBeat, endBeat]` plus a configurable overhang tail (`tailSeconds`, default `2.0s` or 1 bar) to capture reverb/delay/synth release tails.
- Folds (sums) the rendered overhang tail cleanly back onto the opening frames `[0, tailFrames]` with a short 5 ms boundary micro-fade so looping the exported WAV produces **zero clicks or pops** at the wrap point.
- Normalizes the finished loop to `targetLufs` using `src/LoudnessMeter.h` (BS.1770 K-weighted gated LUFS) while clamping true peak `<= -1.0 dBFS`.
