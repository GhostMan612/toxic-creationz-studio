## 1. File-by-File Implementation Scope

### A. Identification (`mcp/audio_identify_worker.py` [New], `src/DawIpcServer.cpp`, `mcp/daw_mcp_server.py`)
1. **Python worker (`mcp/audio_identify_worker.py`, zero-dependency stdlib coarse path + lazy optional `numpy`/`librosa` fine path):**
   - `identify_clip(wav_path, enrolled_voices=None, voice_prints_dir=None)` → `{ "instruments": [{ "family": "drums"|"bass"|"keys"|"guitar"|"vocal"|"sfx"|"unknown", "confidence": 0..1 }], "key": "Am"|None, "bpm": float|None, "speaker": { "voice_id": str, "confidence": 0..1 }|None, "fingerprint": str, "duration_sec": float, "method": "coarse"|"fine" }`.
   - Coarse stdlib-only tagging works with zero extra packages (transient energy → drums, sub-150 Hz dominance → bass, harmonic/formant band → vocal); finer classification activates only when `numpy`/`librosa` are present and sets `"method": "fine"`.
   - Speaker matching compares against enrolled local voice prints (§1.B) and returns `None` below threshold — **never guesses a name**.
   - Deterministic audio-content hash (`fingerprint`) for duplicate/near-duplicate take detection.
2. **New C++ JSON-RPC primitive (`src/DawIpcServer.cpp`):**
   - `audio.get_clip_info`: `{ "track_index": int, "clip_index"?: 0, "clip_name"?: string }` → `{ "track_index", "clip_name", "file_path", "start_beat", "duration_sec", "bpm" }`.
3. **New FastMCP tool (`mcp/daw_mcp_server.py`):**
   - `identify_audio_clip(file_path=None, track_index=None, clip_index=0, clip_name=None)` — resolves `file_path` via `audio.get_clip_info` when a track/clip is supplied, then runs `identify_clip(...)` in `asyncio.to_thread` (15 s timeout).

### B. Strictly Local-Only Voice Cloning (`mcp/voice_clone_worker.py` [New], `mcp/daw_mcp_server.py`)
1. **Local-only voice prints (`~/Documents/Toxic Creationz Studio/VoicePrints/<voice_id>/`, overridable via `voice_prints_dir` for isolated tests):**
   - Stores operator-supplied reference WAV (10–60 s, 44.1 kHz), `voice.json` (`voice_id`, display name, enrolled date, backend, consent note), and local embedding artefact.
   - Voice prints are **never created from session audio** and **never uploaded to any cloud service** (100% local-only).
2. **Enrollment (`enroll_voice(voice_id, name, reference_wav, consent=False, overwrite=False, voice_prints_dir=None)`):**
   - `consent` must be literally `True` or raises a validation error (`code: -32602`) — no silent enrollment, no default `True`.
   - Validates reference WAV (exists, duration 10–60 s, sample rate, non-silent energy); refuses overwrite unless `overwrite=True`.
3. **Local-Only Synthesis (`generate_voice_line(voice_id, text, output_wav, emotion="neutral", voice_prints_dir=None)`):**
   - Requires `voice_id` to exist in `VoicePrints/`; unknown `voice_id` raises an explicit error.
   - Uses a **local zero-shot cloning model only** (e.g., XTTS-v2 via lazy import). **If the local cloning backend/model is absent or fails, the call MUST return an explicit error (`status: "unavailable"`) — NEVER silently substitute a different voice or fallback synth.**
4. **Management (`list_voices(voice_prints_dir=None)` & `forget_voice(voice_id=None, delete_all=False, voice_prints_dir=None)`):**
   - `list_voices` returns enrolled metadata only (never raw audio).
   - `forget_voice` deletes one print by `voice_id` or all prints when `delete_all=True`.
5. **New FastMCP tools (`mcp/daw_mcp_server.py`):** `enroll_voice(...)`, `list_voices()`, `forget_voice(...)`, and `generate_vo_line(voice_id, text, track_index=-1, emotion="neutral")` (runs `generate_voice_line` in `asyncio.to_thread` and imports the resulting WAV via `audio.import_file`).

### C. Generation Scale-Up & Single-Undo Multi-Stem Import (`mcp/ai_audio_worker.py`, `src/DawIpcServer.cpp`, `mcp/daw_mcp_server.py`, `scripts/package-windows.ps1`)
1. **`generate_arrangement` (`mcp/ai_audio_worker.py`):**
   - `generate_arrangement(prompt, output_dir, key="Am", bpm=124.0, style="trap", stems=("drums","bass","lead","pad"), reference_wav=None)` — when `reference_wav` is supplied, runs `identify_clip(reference_wav)` first to condition `key`/`bpm`/style, then generates one WAV per requested stem through `generate_stem` (deterministic offline fallback synth covers every stem when no cloud backend is installed).
   - Extend `generate_stem(..., reference_wav=None)` similarly for single-stem style conditioning.
2. **New C++ JSON-RPC primitive (`src/DawIpcServer.cpp`):**
   - `audio.import_arrangement`: `{ "stems": [{ "name": string, "file_path": string, "start_beat"?: 0.0 }, ...] }` — creates one track per stem and imports each WAV inside **one single `UndoManager` transaction** (one undo removes the entire arrangement) and returns `{ "tracks_created": int, "clips_imported": int, "track_indices": [...] }`.
3. **New FastMCP tool (`mcp/daw_mcp_server.py`):** `generate_arrangement(...)` → generates stems via `asyncio.to_thread` (60 s timeout) and imports them into the DAW via `audio.import_arrangement`.
